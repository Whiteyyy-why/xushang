## 性能基准

场景：本地 Git，1,000 个小文件，100 条历史记录，20 次列表与详情请求。

| 指标 | 结果 |
|---|---:|
| 首次保存（含完整扫描） | 3,366 ms |
| 服务重新启动（含加载数据） | 134 ms |
| 列表 + 详情请求中位数 | 30 ms |
| 列表 + 详情请求 P95 | 32 ms |
| 详情响应体 | 89 KB |

原始数据见 performance.json。结果是本机合成场景，不是普遍延迟保证。

## 环境边界

- Windows + Node.js 24 验证；普通目录与 Git 均使用真实临时文件。
- macOS / Linux 的通用文件与 HTTP 逻辑有实现，未在相应操作系统运行验收。
- VS Code 打开参数与越界防护通过自动化；桌面编辑器端到端启动未作为成功项报告。
- 本地文件夹选择器提供 Windows 原生对话框；目录输入方式已用于核心流程验证。
